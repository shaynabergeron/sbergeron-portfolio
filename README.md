# Shayna Bergeron — Portfolio

A personal developer portfolio built with Next.js, React, TypeScript, and Sass. It includes sections for projects, skills, experience, résumé, and contact.

## Run locally

You’ll need Node.js 24 and npm.

```bash
nvm use
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Useful commands

```bash
npm run build      # Build for production
npm run start      # Run the production build
npm run lint       # Check code style
npm test           # Run tests
npm run typecheck  # Check TypeScript
```

The contact form needs a Resend API key and verified sender address in `.env.local` to send email. See `.env.example` for the required settings.
